📜 HISTOIRE DU SIGNAL

Les capteurs de l'Observatoire ont détecté une anomalie réseau sans précédent provenant d'une ancienne structure Nomai. Ce flux de données, baptisé Projet Aster, semble être la mémoire résiduelle d'un membre de ce peuple disparu.

Cependant, le signal est instable. Il est lié à l'activité de notre soleil : dès que vous initiez la liaison, vous entrez dans une fenêtre temporelle critique. L'agent Aster a laissé un serveur derrière lui, protégé avec une rigueur inhabituelle, comme s'il craignait que ces informations ne tombent entre de mauvaises mains avant la fin du cycle.

🗿 LE LIEN MÉMORIEL

Votre conscience est liée à une statue Nomai. Ce lien est précieux mais fragile :

  • Le Compteur de Synchronisation : La statue ne pourra supporter que 10 synchronisations.
  • Le Sceau de l'Explorateur : Si vous extrayez le Flag à temps, un Certificat d'Exploration sera généré.
  • Le Vide : Si la statue se brise, votre réussite restera anonyme, perdue dans le vide spatial.
